# VECR implementation status — 2026-10-19

The pre-release library has a canonical `ExecuteEdge` operation with distinct arrival, bounded traversal, qualified strip survey and combined traversal-and-survey obligations. The agent owns the attempt state machine, telemetry consumption, safety arbitration and typed reports. The SDK, CLI and example consume this API. The agent accepts only straight two-point routes, computes survey intervals from bounded nadir capture metadata, and restricts capture submission to a configured mTLS sensor client and calibration ID. These inputs are still trusted assertions from the sensor producer, not independently validated camera evidence. The simulator-only recovery option performs bounded re-entry and return-to-B dispatch; it is disabled by default and has no live MAVLink recovery qualification. Attempt retry/history is idempotent within one running agent process and is not durable across restart.

The old state-acceptance research simulator, results and isolated public core were removed from the active tree after SHA-256-verified archives. Product backends, telemetry, authority, data transport, logging and associated tests remain. See `CLEANUP_INVENTORY.md`.

The deterministic VECR strip experiment has frozen v1 outputs and amended v2 outputs. V2 models eight of the requested 21 scenario IDs, 100 seeds per ID, and four paired methods. Private raster truth is separate from the verifier's observed metadata. The model uses geometric replay rather than the production agent/backend; its figures do not establish flight or live sensor performance. See `results/vecr/reports/CORE_RESULTS_V2_100_SEEDS.md` and its manifest.

Regression tests exercise the SDK → Agent → SimBackend path with independent simulator truth, successful gap repair and a motor failure during repair. The versioned [agent-backed v3 pilot](../../results/vecr/agent_pilot_v3/README.md) records those two attempts, raw traces, a configuration and hash manifest, and a figure. These are integration checks, not a statistical campaign. No current VECR SITL campaign, Raspberry Pi timing study, or peer/server goodput campaign has been executed. A live camera evidence source, independent SITL truth, full 21-scenario matrix, fair agent-backed B2 comparison and publication-grade confidence intervals remain open.
