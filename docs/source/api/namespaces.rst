Namespaces
==========

``swarmkit::client``
   Client-side SDK types: single-agent ``Client``, fleet ``SwarmClient``,
   subscriptions, goals, reports, data messages, artifacts, and YAML loaders.

``swarmkit::commands``
   Protocol-neutral command variants and dispatch metadata used by clients and
   agent backends.

``swarmkit::agent``
   Agent-side server configuration, command authority arbitration, backend
   registry, and backend interfaces.

``swarmkit::core``
   Common result/error types, telemetry model, transport-security helpers, and
   logging facade.
